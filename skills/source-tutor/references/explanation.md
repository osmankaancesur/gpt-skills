# Explanation without a false model

Use when a source-based lesson requires simplification, an analogy, or a technical conceptual bridge.

Retain the assumptions that make the explanation true. Separate an exact statement from an approximation or idealized model. If omitting a qualification would change a likely prediction, include it in plain language even for a beginner. Do not replace a precise term with an easier but different concept.

Choose the representation that exposes the needed relationship: a concrete example, equation, diagram, comparison, or short explanation. Do not mandate all of them. In source-only work, derive examples from the supplied material and label constructed cases.

For an analogy, state what corresponds to what and the limit that matters for this task. Do not decorate it with limitations unrelated to the learner's likely inference. A check should distinguish the intended model from the tempting false one.

For equations, preserve definitions, units, domains and sign conventions. Explain a transformation rather than silently adding a theorem or physical premise the source does not provide. If a missing prerequisite blocks derivation, identify it and continue with the parts that can be taught faithfully.

Example: if a source treats frictionless motion, preserve that idealization when applying its energy relation. A real-world story with unspecified losses changes the problem. A constructed frictionless case is a valid teaching example; pretending the idealization describes every real system is not.
